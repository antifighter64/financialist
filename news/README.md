# Financialist news pipeline
This is a static ZIP, not a live CMS. Updating the ZIP does not deploy the site; deploy through Boris's Vercel project. Put verified original articles into `news/articles.json` as a JSON array, run `python3 news/build-news.py`, inspect the result, then deploy. No invented stories for quotas.

Each article: `slug` (lowercase kebab case, stable), `title`, `description`, `author` (approved real byline), `date_published` and `date_modified` (true publication ISO 8601 timestamps with timezone), `body` (array of original paragraphs), `sources` (array of `{label,url}` to verified external original source), `internal_links` (array of `{label,path}` to a relevant existing Financialist section). The script checks structure, not factual accuracy. Never use sample records as published stories. The news sitemap contains only the last two days of published articles, while the main sitemap retains all article URLs. Do not restamp an old article to make it fresh. Google News inclusion is not guaranteed by markup or sitemap.
